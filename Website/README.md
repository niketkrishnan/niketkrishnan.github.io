# My Personal Portfolio 👨‍💻

This repository showcases my personal portfolio, which is built using **HTML**, **CSS**, and **JavaScript**. It's a single-page website that highlights my skills, projects, and contact information.

---

## 🚀 Features

* **Responsive Design**: The website is fully responsive, ensuring it looks great on all devices, from desktops to mobile phones.
* **Interactive Elements**: I've used **JavaScript** to add interactive features, such as smooth scrolling and dynamic project cards.
* **Clean and Modern UI**: The design is clean and modern, focusing on a great user experience.
* **Project Showcase**: The portfolio includes a dedicated section to display my key projects with links to live demos and source code.
* **Contact Form**: Visitors can easily get in touch with me through a simple and effective contact form.

---

## 🛠️ Technologies Used

* **HTML5**: For structuring the content.
* **CSS3**: For styling and layout. I utilized flexbox and grid for a robust and responsive design.
* **JavaScript (ES6+)**: For adding interactivity and dynamic behavior.
